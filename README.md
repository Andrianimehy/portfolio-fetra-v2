# Athelstan Agency

Site vitrine de **Athelstan Agency**, spécialisé dans la création web, l’e-commerce et les solutions digitales sur mesure.

## Stack

- React
- JavaScript / TypeScript
- Node.js / REST API
- Supabase / PostgreSQL
- Shopify / Magento / WordPress / WooCommerce
- Sass

## Développement local

```bash
npm install
npm start
```

Build de production :

```bash
npm run build
```

## Déploiement

Le projet est connecté à GitHub et déployé sur Vercel.

Production : https://athelstan-agency.vercel.app/
